# ⚰️ Reanimator

> Raise dead repos. Then survive Death.

**Reanimator** is a necromancer's workbench for dead code. Pick an abandoned GitHub repo from the graveyard, **raise** it so it runs again on a modern toolchain — proven by real checks, a heart monitor climbing from flatline to a pulse — and then **Death** comes to break what you revived. Death's attack is the [Poltergeist](../poltergeist/README.md) engine red-teaming the app you just revived; whatever it breaks is a real flaw. You read the wounds and **heal** them with Kiro, your familiar, until the project survives him.

Our entry for **Kiroween 2026** (Frankenstein). The whole thing is drawn in a necromancer's dot-matrix art style.

**Status:** docs first; the app is being built inside the hacking window.
